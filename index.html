Problem
Recruiters, collaborators and agencies all need the same facts in a different shape — kept in sync by hand.
Approach
One static site, no framework and no build step. A token-based design system, a hand-written interpreter for the console below, eight locales with right-to-left support, and a print stylesheet for clean A4 output.

Python · CLI

Terminal network toolkit

Local
Problem
Diagnosing a network meant running four utilities and correlating their output by eye.
Approach
A single Python command-line tool that runs host discovery, port scanning and latency probes concurrently on asyncio, then prints one report. Standard library only.
Result
Concurrency turns a serial subnet sweep into a parallel one. The speedup is not quoted here because it has not been measured under controlled conditions — the number goes up when the benchmark does, and not before.
